## Rules

1. **Effort and deadline:** about 6–8 hours of hands-on work, submitted within 7 calendar days of receiving the kit. Deadline, submission, and any clarification questions go through your HR contact.
2. **AI tools and models:** you may use any LLM, provider, coding agent, or AI-assisted tool. **State which LLMs/models and AI tools you used** (provider, model, and what you used them for) in your submission.
3. **Costs:** any LLM or API costs you incur are **not reimbursed**. Nothing in this kit requires a paid service.
4. **Reviewer must be able to run your PoC through the provided portal**, configured via `ENGINE_COMMAND` as described in `START_HERE.md`. Running on mocked or recorded model responses is acceptable, as long as the code path is real and runnable.
5. **Third-party libraries and frameworks** (agent frameworks, MCP SDKs, etc.) are allowed.
6. **Do not modify `portal/`, `sample-app/`, `outage-feed/`, or `reference-docs/`.** Your PoC connects to the portal only through its engine contract; the other folders are the inputs your PoC analyzes.
7. **Submission:** a Git repository with its commit history preserved. Exact channel and format come via HR.
8. **Confidentiality:** do not publish this kit or your solution publicly.

Good luck. We look forward to discussing your solution with you.
